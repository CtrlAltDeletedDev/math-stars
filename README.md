# Math Stars ⭐

A math learning app for kids going into 1st grade. Built with React Native + Expo.

## Running on iPad via GitHub Codespaces (no computer needed)

### Step 1 — Install Expo Go on the iPad
Search **"Expo Go"** in the App Store and install it (free).

### Step 2 — Open the repo in Codespaces
1. Go to this GitHub repo in your phone/iPad browser
2. Tap the green **Code** button
3. Tap the **Codespaces** tab
4. Tap **Create codespace on main** (or the current branch)
5. Wait ~2 minutes for it to set up — it installs everything automatically

### Step 3 — Start the app
In the Codespaces terminal, run:
```bash
npx expo start --tunnel
```

After ~30 seconds a **QR code** will appear in the terminal.

### Step 4 — Open on iPad
- Open **Expo Go** on the iPad
- Tap **Scan QR Code**
- Point it at the QR code on your screen
- The app will load! 🎉

> **Note:** The Codespace must stay open while she's playing. GitHub gives 60 free hours/month — plenty for daily use. Just close the browser tab when done to stop the timer.

## Categories & Levels

| Category | Levels |
|---|---|
| ➕ Adding & Taking Away | Add to 5 → 10 → 20 → Subtract → Mixed |
| 🔢 Counting & Numbers | Count objects → Order → Compare |
| 🔷 Shapes & Patterns | Basic shapes → More shapes → Patterns |
| 🚀 Skip Counting | By 2s → 5s → 10s → ×2 → ×5 → ×10 |

Pass a level with **80% correct** to unlock the next one (1–3 ⭐ based on score).
Wrong answers come back sooner thanks to spaced repetition.
